# Kamas counter

Application Flask qui lit une capture d'écran du chat et additionne les montants de kamas (monnaie du jeu Dofus) détectés par OCR (EasyOCR).

**Aperçu de l'interface : https://mvtteo.github.io/kamas_counter/** — l'analyse OCR tourne côté serveur, elle n'est donc pas disponible dans l'aperçu statique.

## Lancer en local

```bash
pip install -r requirements.txt
python app.py      # http://localhost:5000
```
